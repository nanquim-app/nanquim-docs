# Concorrentes e referências

Resumo do que importa para decidir; o levantamento completo está no repositório do app, em `docs/research/01-code-benchmarks.md`, `02-interface-benchmarks.md` e `03-product-references.md` ([github.com/oandre/ai-ide-for-business](https://github.com/oandre/ai-ide-for-business/tree/main/docs/research)).

| Produto | Forte em | Fraco em | O que copiamos | Onde ganhamos |
|---|---|---|---|---|
| **Claude Desktop / Cowork** | Loop do agente, caixa de texto, ícones de contexto | Ver o resultado, histórico, lock-in de fornecedor | Conversa no centro, composer, ícones no alto | Palco com diff e revisão; git; qualquer modelo |
| **Claude Docs** | Edição inline com IA, comentários ancorados com "Ask Claude" | Arquivo preso ao serviço | Editar no documento com diff, comentar e passar ao assistente | Arquivo é Markdown no seu repositório |
| **Obsidian** | Texto puro, vault, plugins, git via plugin | Não é nativo de IA nem de time | Vault abre como está, wikilinks, callouts | Agente, revisão, time |
| **Notion** | Renderiza muitos tipos de conteúdo | IA fraca, sem HTML, histórico limitado, fechado | Densidade e polimento | Histórico real, diff, desfazer, aberto |
| **Cursor / Claude Code** | Harness de agente, skills, CLAUDE.md | Feito para código e para quem programa | Convenções de skills e agentes | Vocabulário e formatos de negócio |
| **Codex Automations / Cowork agendado** | Execuções agendadas | Resultado não cai como proposta revisável | Agendamento | Resultado como rascunho |

Reavalie este quadro a cada trimestre; produtos de IA mudam em semanas.
